# UI Phase 1.2 Windows 人工验收清单

自动 GUI Smoke Test 不能替代人工视觉和交互验收。请在下载的 Windows onedir 包上执行以下检查。

## 环境组合

- [ ] 1366×768，100% DPI
- [ ] 1920×1080，100% DPI
- [ ] 1920×1080，125% DPI
- [ ] 1920×1080，150% DPI

## 启动与首页

- [ ] 双击 `IBIS_Automation.exe`，无需 Python 即可启动
- [ ] 无最近项目时显示项目首页、三个入口和“未打开项目”
- [ ] 有最近项目时可恢复或从最近项目双击打开
- [ ] 最近项目路径失效时显示中文错误，软件不崩溃
- [ ] 首页概要中的 IO Top、DRV/RCV、Case 数量与项目一致
- [ ] 推荐下一步随 DIRTY 和输入检查结果变化

## 中文和布局

- [ ] 按钮、Tab、状态栏、弹窗、Tooltip 均为中文；技术术语可保留
- [ ] 顶部当前项目和保存状态始终清晰可见
- [ ] 任何页面点击“项目首页”可返回，草稿不丢失
- [ ] 左右区域可调整；长配置可纵向滚动；表格可横向滚动
- [ ] 中文字体正常，无方框或启动阻塞
- [ ] 长路径可以完整查看，目录按钮可打开对应目录

## 保存流程

- [ ] 修改某模块 `Tr TYP` 后状态显示“有未保存修改”
- [ ] 只点击一次“保存配置”即可验证、应用和持久化
- [ ] 关闭再打开后修改保持
- [ ] 输入非法 Voltage Domain 后保存失败，错误字段明确
- [ ] 保存失败后旧项目仍有效，编辑框中的草稿仍保留
- [ ] 退出、切换项目、重新导入时有保存/放弃/取消提示
- [ ] 原始 Config Excel 的时间、Hash 和内容不变

## 输入文件

- [ ] MSI 默认表每行代表一个 IO Top 映射，不与 Excel/Sheet 层级混排
- [ ] “查看扫描详情”可展开/收起 Excel 与 Sheet
- [ ] 多 Excel、多 Sheet 数量正确，歧义显示“匹配失败”
- [ ] SPF 按 IO Top 与 MAX/TYP/MIN 展示文件、TOP_SUBCKT 和 Pin 数量
- [ ] Model 页仅显示文件存在性，不声称电气模型通过
- [ ] “刷新输入检查”重新扫描且不修改源文件

## 阶段边界

- [ ] 所有 Case 初始状态为“未生成”
- [ ] 生成结果、任务监控明确显示暂未开放
- [ ] UI-2/UI-3/UI-4 功能没有可产生虚假成功的按钮

## 版本证据

- [ ] “关于软件”显示版本 `0.1.2`
- [ ] Git Commit 与 GitHub Actions 构建 Commit 一致
- [ ] 解压目录包含 `IBIS_Automation.exe`、`_internal/` 和 `README.txt`
